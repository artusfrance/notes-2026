   pip install libpff-python
2. Enregistrer le script pstsearch.py (fourni) et lancer :
   python3 pstsearch.py "chemin/vers/catherine.laudenbach@orange.fr.pst" resultats_vesgre.json
   (durée : quelques minutes pour 1,2 Go)

   Vesgre, inondation, crue, batardeau, pompe, fausse rivière, berges, syndicat, GEMAPI,
   catastrophe naturelle, Polyexpert, sinistre, mairie, moulin, vannes, bief,
